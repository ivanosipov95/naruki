# naruki.online

Статический сайт-калькулятор зарплаты "на руки" для России (naruki.online).

## Что делает сайт

- Калькулятор НДФЛ по прогрессивной шкале 2026 года: 13% / 15% / 18% / 20% / 22%
- Показывает доход на руки по месяцам, налоги по ставкам, итоговую сумму
- Второй калькулятор — "Повышение зарплаты" (raise.html)
- Параметры синхронизируются в URL (`?gross=50000&start=1`) — можно делиться ссылкой

## Технологии

- Чистый HTML + CSS + Vanilla JS (без фреймворков и сборщиков)
- Шрифты: Manrope + Playfair Display (woff2, self-hosted)
- Аналитика: Яндекс.Метрика
- Светлая/тёмная тема (сохраняется в localStorage, применяется до рендера)

## Ключевые файлы

| Файл | Назначение |
|------|-----------|
| `src/index.html` | Главная страница — калькулятор зарплаты |
| `src/raise.html` | Калькулятор повышения зарплаты |
| `src/app.js` | Логика расчётов, рендеринг, URL-параметры |
| `src/raise.js` | Логика калькулятора повышения |
| `src/styles.css` | CSS с переменными для тем, адаптив |
| `src/theme.js` | Переключение тёмной/светлой темы |
| `src/analytics.js` | Яндекс.Метрика с cookie-баннером |
| `scripts/cache_bust.py` | Cache-busting — обновляет `?v=...` у ссылок на статику |

## Логика расчёта (app.js)

Ставки НДФЛ (brackets):
- до 2 400 000 — 13%
- 2 400 000 – 5 000 000 — 15%
- 5 000 000 – 20 000 000 — 18%
- 20 000 000 – 50 000 000 — 20%
- свыше 50 000 000 — 22%

Расчёт накопительный: каждый месяц считается нарастающий доход с начала года, налог по шкале применяется к накопленной сумме, из разницы выводится налог за текущий месяц.

## Deploy

- CI через GitHub Actions:
  - `deploy.yml` — деплой по FTP вручную (workflow_dispatch), указывается версия
  - `switch-release.yml` — переключение/откат на другую версию
- Релизы хранятся в `/releases/{version}/` на сервере, затем промотируются в корень
- Перед деплоем запускается `scripts/cache_bust.py` для обновления хешей

## Разработка

Нет системы сборки. Редактируй файлы в `src/` напрямую. После изменений статики (CSS, JS, изображения) cache_bust.py автоматически обновит версии при деплое.
